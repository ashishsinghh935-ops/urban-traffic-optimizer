# Urban Traffic Flow & Route Optimization Solver

A MATLAB-based simulation and linear algebra model designed to optimize urban traffic networks, model intersection flow conservation, detect traffic bottlenecks, and visualize network topology.

## Features
- **Linear Algebra Solver**: Computes traffic volume vectors ($Ax = b$) across intersections using MATLAB.
- **Automated Bottleneck Detector**: Flags intersections exceeding safe capacity limits.
- **Network Graph Visualization**: Generates a directed graph topology of the road network.

## Requirements
- MATLAB (with core matrix manipulation support)

## Usage
1. Open `traffic_simulator.m` in MATLAB Online or MATLAB desktop.
2. Run the script to calculate traffic volumes, view congestion alerts, and generate the network plot.
